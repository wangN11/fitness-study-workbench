减肥学习综合工作台 · 说明
============================

这是一个纯本地、离线可用的「工作台」，所有数据只存在你自己的设备里，
不会上传任何内容。可作为桌面软件，也可作为手机 App（PWA）使用。


【🌐 云端版（手机可访问，推荐）】
公开地址：https://wangn11.github.io/fitness-study-workbench/
· 手机浏览器打开上面的链接，即可像 App 一样全屏使用。
· 断网也能用（首次打开后会缓存到本地）。
· 所有打卡记录保存在你手机浏览器本地，换设备不会同步。


【📱 手机「添加到主屏幕」（变成真 App）】
  iPhone / iPad（Safari）：
    1) 用 Safari 打开上面的云端地址；
    2) 点底部「分享」按钮（方框带向上箭头）；
    3) 选择「添加到主屏幕」；
    4) 确认名称后点「添加」。
    → 桌面出现图标，点击即以全屏 App 打开，无浏览器地址栏。

  Android（Chrome / Edge）：
    1) 用 Chrome 打开上面的云端地址；
    2) 点右上角 ⋮ →「安装应用 / 将应用安装到桌面」；
    3) 点「安装」。
    → 桌面出现「减肥学习综合工作台」图标，点击即全屏使用。


【💻 桌面版（本文件夹）】
把整个「减肥学习综合工作台」文件夹复制到电脑桌面，双击对应启动器：
  • Windows  →  启动工作台.bat
  • macOS    →  启动工作台.command
  • Linux    →  启动工作台.sh  （或双击「减肥学习综合工作台.desktop」）
会用 Chrome 以独立应用窗口打开（无地址栏，可离线）。

想要更像一个原生 App：用 Chrome 打开 index.html，点 ⋮ →
「将应用安装到桌面 / 创建快捷方式（打开为窗口）」。


【🔄 更新内容后重新部署】
本文件夹已是一个 Git 仓库，连着 GitHub Pages。修改文件后：
    git add -A
    git commit -m "更新说明"
    git push
等待约 1 分钟，云端地址自动更新。


【数据存在哪？】
所有打卡记录保存在浏览器的本地存储（localStorage）中，刷新、关机都不丢。
如需清空：打开工作台首页，点右下角「🗑 清空数据」即可。

  使用说明.txt              本文件
