减肥学习综合工作台 · 桌面 APP 使用说明
========================================

这是一个纯本地、离线可用的「工作台」，所有数据只存在你自己的电脑里，
不会上传任何内容。把它当成一个桌面小软件用即可。


【第一步：放到桌面】
把整个「减肥学习综合工作台」文件夹复制到你的电脑桌面上。


【第二步：双击打开】
根据你的系统，双击对应的启动器即可：

  • Windows  →  启动工作台.bat
  • macOS    →  启动工作台.command
  • Linux    →  启动工作台.sh  （或在桌面双击「减肥学习综合工作台.desktop」）

启动后会用 Chrome 以「独立应用窗口」打开（没有浏览器地址栏，
看起来就和原生软件一样），可以离线使用。


【想要更像一个真正的 App？（可选）】
方式 A：固定到任务栏 / 程序坞
  在打开的应用窗口上，右键 →「固定到任务栏 / 添加到程序坞」，以后一点就开。

方式 B：安装成桌面应用（推荐，离线 + 独立图标）
  1) 用 Chrome 打开本文件夹里的 index.html（地址栏输入 file:// 路径，
     或直接把 index.html 拖进 Chrome）；
  2) 点击右上角 ⋮ →「将应用安装到桌面 / 创建快捷方式」，并勾选「打开为窗口」；
  3) 桌面上就会出现「减肥学习综合工作台」图标，双击即以 App 形式打开。

  （Edge 浏览器同理：⋮ →「应用」→「将此站点作为应用安装」。）


【数据存在哪？】
所有打卡记录保存在浏览器的本地存储（localStorage）中，刷新、关机都不丢。
如需清空：打开工作台首页，点右下角「🗑 清空数据」即可。


【没有 Chrome 怎么办？】
启动器会自动退回用系统默认浏览器打开（功能完全一样，只是窗口带地址栏）。
建议安装 Chrome / Edge 以获得最佳「应用」体验。


文件夹内容说明
--------------
  index.html              工作台主程序（双击启动器即打开它）
  manifest.webmanifest    PWA 清单（用于「安装到桌面」）
  sw.js                  离线缓存（联网安装后断网也能用）
  icon-192.png / icon-512.png   应用图标
  启动工作台.bat /.command /.sh  各系统一键启动器
  减肥学习综合工作台.desktop     Linux 桌面启动器
  使用说明.txt            本文件
